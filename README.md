高质量居住指南
不是让你搬去更好的地方，是让你在负担得起的地方，把日子过稳。
先说清楚这不是什么：不是宜居城市排行榜，不是房源平台，不是「辞职搬去小城」爆款帖，也不是一份看完让人更焦虑的移居长文。
这里暂时也没有能点开的 App，连一行代码都还没有——目前它只是一堆写得很较真的设计文档。
那它想干什么？ 把「我到底该住哪儿」这件模糊的事，拆到能往下走为止，而不是又让你多收藏一篇帖子。
你大概遇到过这种局面
- 刷完几篇「某座城市适合长期住」，热血上来了，然后发现完全不知道该住哪个片区。
- 房租看着能接受，搬进去才知道楼下没菜场，最近的三甲医院要跨半个城。
- 想算「一个月到底得花多少」，搜到的都是别人的平均数，跟你的过法对不上。
- 打开地图一个个数周边有什么，数到一半就关掉了。
关于「住哪儿」的信息其实不少，可惜它们互相不认识：讲城市的落不到片区，讲房子的不讲日常，讲单店的讲不了生活圈，讲消费水平的是别人的平均分。于是每一步都有答案，连起来却没有结论。
这份指南是写给谁的
写给不想再被「往上走」推着跑的人。
不是要更多的机会、更快的通勤、更大的房子；是想知道一个月花多少才不慌，走几分钟能买到菜，夜里吵不吵，附近有没有能看病的地儿，以及——这份日子我撑不撑得住。
大多数「宜居」榜单默认每个人都在往上够：产业、薪资、上升空间、学区。可有人要的刚好反过来：少一点消耗，多一点可预期。不是不努力，是不想把全部力气都花在「待在这座城」这件事上。
所以这里不劝你搬，也不劝你留。你要是想在原地过得轻一点，它一样有用。
名字为什么这么朴素
没叫「逃离」，没叫「最宜居」，也没叫「人生最优解」。
「高质量」听起来很像要你花钱、要你升级，在这儿意思正好相反：这套日子你负担得起，也过得下去。房租、菜场、通勤、安静、看得病，这几样凑起来，比任何排名都更接近「过得好」。
名字最后就定得这么朴素。因为它要解决的也不是什么宏大的问题，无非是一个人站在地图前面，想知道自己能不能在这儿安安稳稳住下来。
故事是从哪儿开始的
大概起于一个很常见的瞬间：你认真研究完一座城，发现所有资料都在回答「这座城好不好」，没有一个在回答「我在这儿行不行」。
于是问题被换了个方向——不再是「哪座城市更宜居」，而是「用我能承担的钱，我能不能在这儿把日常过顺」。
这一换，好多原来的答案就不够用了。一座城的平均分说明不了你那条街；房租便宜不意味着一个月不慌；一家网红店救不了没有菜场的片区。得把城市、片区、预算、周边放在同一张桌上一起看，才可能有个落得了地的结论。
这份指南想补的，就是中间那几段空白。
它打开之后大概长这样
你不用先想好城市名字。先说你在意什么：别太吵、冬天别太阴、一个月别超过这个数、希望走路能到菜场。
它把这些话变成能比较的条件，先给出几座还过得去的城；然后不急着推房子，先陪你看城里的生活圈——安不安静、好不好走、邻里是什么气氛；接着把房租和日常开销一起摆上来，超预算的先放一边，缺数据的也老实标出来，不假装算过；最后才摊开周边，一公里内有什么、两公里内有什么，清单和地图上那个圈一起动。
一圈看下来，你可能换了座城，也可能发现现在住的这片就挺好。两种都算有答案。
花掉的是一次把问题问清楚的时间，换回的是少踩几个坑。也别指望它替你拍板——最后那一下，还是你自己说了算。
几个不太一样的决定
- 分数由你自己填：0–100，默认值是空的。不预置 50，不替你揣测，也不在没有真实样本前用算法「修正」你打的分。
- 生活成本是硬条件，不是评分项：房租上限和日常开销预算只用来筛，不进任何分数、不公开、也不拿去排名。
- 不排「最佳城市」：只按你此刻的偏好给能比较的结论；点赞多不多、人气高不高，跟好不好住无关。
- 城市、片区、场所分开算：一座城的平均分不该盖过你那条街，地铁站也不该被逼着打「性价比」的分。
- 不造假：没有评价就写没有，不用样例内容填空，不拿别人的平均数冒充你的生活。
- 位置这件事很克制：不追踪你、不公开他人位置，住宅对外只到片区级。
