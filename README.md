# 高质量居住指南

## 这个项目要做什么

想做一份「住哪儿」的指南，写给不想再被「往上走」推着跑的人。

不是宜居城市排行榜，不是房源平台，不是「辞职搬去小城」爆款帖，也不是一份看完让人更焦虑的移居长文。它要做的事很具体：**用你能承担的钱，找到一处能把日常过顺的地方，并且在搬过去之前就知道那儿大概是什么样。**

关于「住哪儿」的信息其实不少，可惜它们互相不认识：讲城市的落不到片区，讲房子的不讲日常，讲单店的讲不了生活圈，讲消费水平的是别人的平均数。于是每一步都有答案，连起来却没有结论。

这份指南想补的就是中间那几段空白。而且它从一开始就不该由一个人写完——最要紧的那种知识不在任何资料里，**「我在这儿真的住得挺顺」只装在住过的人脑子里。**

---

## 为什么需要大家一起写

大多数「宜居」榜单默认每个人都在往上够：产业、薪资、上升空间、学区。可有人要的刚好反过来：一个月花多少才不慌，走几分钟能买到菜，夜里吵不吵，附近有没有能看病的地儿，**以及这份日子我撑不撑得住**。

这些事没有官方答案。安静不安静，得有人在那条街上睡过；菜场好不好逛，得有人天天拎着袋子走过；房租涨没涨，得住满一年才知道。谁坐在屋里都整理不出标准答案，它散在住过的人那儿，一人知道一小块。

所以这份指南是**大家一起写**的：每个人把自己那一小块补上来，慢慢拼出个样子。不打分，不评「最佳」，不按人气排，也不劝你搬、不劝你留。你要是想在原地过得轻一点，它一样有用。

**空白里也有你的一段。**

---

## 想解决的那几件具体的事

- 刷完几篇「某座城市适合长期住」，热血上来了，然后发现完全不知道该住哪个片区。
- 房租看着能接受，搬进去才知道楼下没菜场，最近的三甲医院要跨半个城。
- 想算「一个月到底得花多少」，搜到的都是别人的平均数，跟你的过法对不上。
- 打开地图一个个数周边有什么，数到一半就关掉了。
- 真住到一处挺顺的地方，想告诉别人，却发现没地方写——发条动态三天就沉了，贴到别处又容易被当成广告。

---

## 名字为什么这么朴素

没叫「逃离」，没叫「最宜居」，也没叫「人生最优解」。

「高质量」听起来很像要你花钱、要你升级，在这儿意思正好相反：**这套日子你负担得起，也过得下去**。房租、菜场、通勤、安静、看得病，这几样凑起来，比任何排名都更接近「过得好」。

它要解决的也不是什么宏大的问题，无非是一个人站在地图前面，想知道自己能不能在这儿安安稳稳住下来。

---

## 故事是从哪儿开始的

大概起于一个很常见的瞬间：你认真研究完一座城，发现所有资料都在回答「这座城好不好」，没有一个在回答「我在这儿行不行」。

问题于是换了个方向——不再是「哪座城市更宜居」，而是「**用我能承担的钱，我能不能在这儿把日常过顺**」。

这一换，好多原来的答案就不够用了。一座城的平均分说明不了你那条街；房租便宜不意味着一个月不慌；一家网红店救不了没有菜场的片区。得把城市、片区、预算、周边放在同一张桌上一起看，才可能有个落得了地的结论。

---

## 它打算怎么回答你

不用先想好城市名字，也不用把要求说得多漂亮。把在意的事一项项自己勾出来就行：别太吵、冬天别太阴、一个月别超过这个数、希望走路能到菜场。

**条件全由你自己选，没选的就留空，不替你猜。** 先给出几座还过得去的城；然后不急着推房子，先陪你看城里的生活圈——安不安静、好不好走、邻里是什么气氛；接着把房租和日常开销一起摆上来，超预算的先放一边，缺数据的也老实标出来，不假装算过；最后才摊开周边，一公里内有什么、两公里内有什么，清单和地图上那个圈一起动。

一圈看下来，你可能换了座城，也可能发现现在住的这片就挺好。两种都算有答案。

花掉的是一次把问题问清楚的时间，换回的是少踩几个坑。也别指望它替你拍板——最后那一下，还是你自己说了算。

## 一起补这份指南

这一页留给 GitHub 上的你直接写。不用装东西，也不用额外注册什么。

**想请你写的**：你自己**真的住过、或长期待过**，觉得适合安稳过日子的地方。可以是居民楼、长租公寓、包月的民宿、能长期落脚的网吧，也可以只写到一个片区——你愿意写到多细，就写到多细。**没住过的不写，替别人总结的不写，从榜单搬来的不写。**

### 几条约定

- **只写自己经历过的**：这是有人住过的清单，不是排行榜，不打分、不评「最佳」、不按人气排。
- **写「大概」，不写「精确」**：不收门牌、坐标、他人住址。这一页对位置比产品里更克制。
- **成本自己算自己的**：写清楚是房租还是日常开销，标「自己填的，没经校验」。没有真实数据就空着，不用样例内容填空。
- **中国香港 / 中国澳门 / 中国台湾**写在「中国」下，按片区写，别当独立国家。
- **你自己写的东西你自己负责**：这里都是个人分享，不是平台认可，未经校验，也不代表任何经营资质或许可。
- **想改、想删**：开个 Issue 说一声，不用解释太多。

为什么放在这一页？一个文件，在 GitHub 上直接看、直接改，谁都能补一行。

## 几个不太一样的决定

- **条件你自己选，分数你自己填**：筛选项拆开摆着，没选就留空；评分 0–100，默认值是空的。不预置 50，不替你揣测，也不在没有真实样本前用算法「修正」你打的分。
- **生活成本是硬条件，不是评分项**：房租上限和日常开销预算只用来筛，不进任何分数、不公开、也不拿去排名。
- **不排「最佳城市」**：只按你此刻的偏好给能比较的结论；点赞多不多、人气高不高，跟好不好住无关。
- **城市、片区、场所分开算**：一座城的平均分不该盖过你那条街，地铁站也不该被逼着打「性价比」的分。
- **不造假**：没有评价就写没有，不用样例内容填空，不拿别人的平均数冒充你的生活。
- **位置这件事很克制**：不追踪你、不公开他人位置，住宅对外只到片区级；这一页的投稿也一样，不收门牌和精确坐标。
- **一起写，不代写**：没有编辑部，也没有标准答案。每一条都来自真的住过的人，写完署自己的名。
